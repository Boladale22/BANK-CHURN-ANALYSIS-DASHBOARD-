# 🏦 Bank Churn Analysis Dashboard

Interactive Power BI dashboard analyzing customer churn patterns and providing actionable business insights.# BANK-CHURN-ANALYSIS-DASHBOARD-


# 📖 Project Overview

The Bank Churn Analysis Dashboard is an interactive Power BI dashboard designed to analyze customer churn patterns and identify the factors influencing customer retention.

The dashboard provides business insights into customer demographics, banking behavior, product usage, and churn trends, helping decision-makers develop strategies to improve customer retention and customer satisfaction.

---

# 🎯 Project Objectives

- Analyze customer churn across different customer segments.
- Identify key drivers of customer churn.
- Monitor customer demographics and banking activities.
- Evaluate customer retention performance.
- Support data-driven business decisions.

# 🧹 Data Cleaning & Preparation

The dataset was cleaned and transformed using Power Query.

The following data preparation steps were performed:

- Removed unnecessary columns
- Corrected data types
- Removed duplicate records
- Removed errors
- Split columns where necessary
- Created conditional columns
- Grouped Age into Age Bands
- Grouped Credit Scores into Credit Score Bands
- Grouped Number of Products
- Grouped Customer Tenure
- Grouped Estimated Salary
- Grouped Customer Balance
- Created relationships between tables
- Built a star schema data model

# 📈 Key Insights

- Overall customer churn rate is **20.37%**.
- Germany recorded the highest number of churned customers.
- Customers with only one product had the highest churn.
- Inactive customers were more likely to leave the bank.
- High-balance customers accounted for the highest number of churned customers.
- Credit score bands showed varying churn behaviour across customer groups.

---

# 💼 Business Recommendations

- Improve retention strategies for inactive customers.
- Encourage customers to adopt multiple banking products.
- Reward loyal customers through personalized offers.
- Focus customer retention efforts on high-churn regions.
- Monitor customers with high balances.
- Strengthen customer engagement through targeted communication.
